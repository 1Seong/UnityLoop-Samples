# UnityLoop

> 이 저장소는 개인 작업 환경 정보(로컬 경로 등)가 들어 있어 공개할 수 없는 원본 저장소를 대신해 마련한 **포트폴리오용 공개 샘플 저장소**입니다. 프로젝트 소개와 핵심 코드 발췌를 제공하며, 전체 소스·프로젝트 설정·개발 이력은 포함하지 않습니다. 샘플은 이해를 돕기 위해 일부 의존성을 생략하거나 재구성했으며, 각 문서에 그 범위를 명시했습니다.

## 프로젝트 소개

UnityLoop는 사람이 고른 Jira 이슈 하나를 계획·구현·검증·PR·CI·수락·머지까지 잇는 에이전트 개발 루프입니다.

Claude Code 안에서 스킬 하나(`/issue`)가 절차를 정하고, 단계별 서브에이전트가 계획과 구현을 맡습니다. 훅은 도구 호출의 허용·차단을, 결정적 스크립트는 단계 통과 여부를 판정합니다. 이슈 구현은 에이전트가 하지만, 이슈 선택·수락·머지는 사람이 결정합니다. 학습용 Unity 프로젝트의 이슈를 수락 거절과 재구현을 거쳐 PR 머지와 Jira 완료까지 처리했습니다.
